# Identidad visual de HEXAOS

Concepto: un hexágono (HEXA = seis) que contiene una H cuya barra central es un pulso, símbolo del tiempo real.
Color principal: turquesa `#19D3C0` (sobre fondos claros, `#00897B`); tinta `#0B0F14`.

| Archivo | Uso |
|---|---|
| `hexaos-logo-dark.svg/png` | Símbolo y palabra sobre fondos oscuros |
| `hexaos-logo-light.svg/png` | Símbolo y palabra sobre fondos claros |
| `hexaos-mark.svg/png` | Solo el símbolo (fondos oscuros) |
| `hexaos-mark-mono.svg` | Símbolo monocromo; hereda `currentColor` |
| `hexaos-icon.svg/png` | Icono de app / favicon (trazos más gruesos para tamaños pequeños) |

El texto del logotipo está convertido a trazados con la fuente Inter (SIL Open Font License), por lo que no necesita fuentes instaladas.
A 16-24 px usa `hexaos-icon`. Los SVG se pueden regenerar con un script propio; los PNG se exportan con fondo transparente.
