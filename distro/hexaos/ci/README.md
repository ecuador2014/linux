# CI de ejemplo
`hexaos-images.yml.example` compila los perfiles x86_64 en GitHub Actions y publica un release con las ISO y las imagenes de disco.
**Esta inactivo y sin validar**: la primera ejecucion fallo antes de obtener un runner (problema de la cuenta/repositorio, no del flujo).
Para usarlo: resuelve ese problema, copia el archivo a `.github/workflows/hexaos-images.yml` (con `git add -f`) y lanzalo desde la pestana Actions.
